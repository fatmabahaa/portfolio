About

A quick look at who I am and how I work.

I'm a Full-Stack Web Developer with hands-on experience in the MEAN stack — Angular, Node.js, Express.js, MongoDB, JavaScript and RESTful APIs. I like building web applications end to end: wiring up the frontend, the backend and the database so they actually work together, not just look good on their own.

Alongside web development, I've also worked with Flutter for mobile app development and picked up data analysis skills through practical training. I'm currently studying Management Information Systems, which gives me a bit of both worlds — the technical build and the bigger picture of how systems support real decisions.

Outside of the stack list, what I actually enjoy is the debugging moment — the one where frontend, backend and API finally agree with each other. Every fixed bug feels a little like a lucky charm landing exactly where it should.

MEAN Stack · Training project (NTI)
AngularNode.jsExpress.jsMongoDB

A web-based system for managing students and their courses, built on the full MEAN stack. The Angular frontend talks to a Node.js/Express REST API, which reads and writes data in MongoDB — so students, courses and enrollments all stay in sync across the app.

It covers the core flow of a course-management tool: adding and editing students, assigning them to courses, and keeping everything backed by a proper database instead of hardcoded data.
